# Mewse（喵织梦）V1 UI 设计初稿

- **文档版本**：v1.0
- **设计阶段**：文字版界面框架稿（已与交互原型对齐）
- **设计依据**：《Mewse（喵织梦）V1 产品需求文档》
- **说明**：本文用于统一 V1 的整体界面方向、页面结构、层级归属与主要交互，不展开具体尺寸、色值及组件规格。旧版《需求&设计-初版草稿》仅作布局思路参考，功能与内容均以 V1 需求为准。

---

## 1. 设计目标与原则

### 1.1 核心体验

让作者打开软件后能够快速找到作品、进入章节并持续写作；写作之外的管理功能保持清晰易找，但不与正文争夺注意力。

### 1.2 设计原则

1. **正文优先**：编辑画布是工作台视觉中心，不设置常驻格式工具栏。
2. **克制而温和**：以留白、层级和轻量分隔塑造界面，减少装饰性元素、无意义动效与自明功能的解释性小字。
3. **本地可信**：清楚呈现保存、同步、冲突与删除状态，让稿件去向可理解、可追溯。
4. **按需出现**：设置、检索、统计、历史快照等功能通过浮层、抽屉或独立页面承载，使用后即可收起。
5. **保持纯文本心智**：界面不提供加粗、斜体等富文本入口，不让用户产生“排版会写入正文”的误解。

---

## 2. 整体信息架构

V1 主要由以下界面组成：

```text
首次启动 / 书库选择
        ↓
书架首页
        ↓
作品写作工作台
 ├─ 单栏写作
 ├─ 双栏对照写作
 ├─ 专注模式
 ├─ 全书检索
 ├─ 历史快照与版本对比
 ├─ 回收站
 └─ 字数明细与码字日历

全局功能：主题切换、正文排版设置、发布格式预设、书库切换
安全功能：外部变更提示、版本冲突处理、危险操作确认
```

常规工作台采用“**左侧目录 + 中央写作区**”的双区结构，严格区分“**整书与全局级操作**（位于最上方工作台顶栏）”与“**单章级操作**（位于章节区顶部栏位）”。底部仅保留必要的保存与字数状态反馈；右侧不设置默认常驻栏，排版、历史快照与回收站等辅助内容以按需抽屉出现。

---

## 3. 整体视觉方向

- **气质**：安静、柔和、可靠，接近舒适的纸张阅读体验，但不做过度拟物化设计。
- **色彩**：界面以低饱和中性色为基底，主题色主要作用于画布、背景与少量强调状态；成功、警告、危险颜色仅用于必要反馈。
- **字体**：界面文字与正文文字分开处理。界面保持清晰易读，正文默认采用适合长时间中文阅读的字体，并允许用户调整。
- **层级**：目录与辅助区域弱化，当前章节标题与正文突出；选中项、当前编辑项和焦点状态需要明确但不过分醒目。
- **主题**：纯白、羊皮纸、淡绿、暗夜四套主题覆盖书架、工作台、浮层与弹窗，通过全端统一的「主题」入口随时切换，避免只切换编辑画布而造成视觉割裂。
- **个人心智**：作为面向个人创作者的纯本地桌面写作软件，界面不引入账号头像、用户资料或冗余的云端状态说明。
- **动效**：仅用于抽屉展开、视图切换、操作结果等轻量反馈，不影响输入与阅读。

## 4. 主要页面设计

### 4.1 首次启动与书库选择

页面以简短产品欢迎语和书库选择操作为核心，说明书库是保存作品的本地文件夹，也可选择云盘同步目录。

主要操作：

- 选择本地文件夹作为书库；
- 已有最近书库时，可快速继续上次使用的位置；
- 提供切换或重新指定书库的入口。

不在首次启动流程中堆叠排版、发布格式等设置，完成书库选择后直接进入书架。

### 4.2 书架首页

**页面目标**：展示作品总览，并让“继续写作”成为最顺手的路径。

**顶部与概览区域**：

- 左上展示应用标识；右上仅放置与工作台一致的全局「主题」切换按钮，不设置用户头像与冗余本地说明文字；
- 主体顶部展示当前书库路径并可点击切换书库（底部亦保留切换入口），同时提供「新建作品」、「导入作品」两个主要操作；
- 作品列表上方提供「码字日历」入口。

**作品区域**：

- 使用网格卡片展示作品；
- 卡片包含封面、作品名称、连载状态、全书字数和最近编辑时间；
- 点击卡片主体直接进入作品工作台；
- 编辑作品信息、从书架移除或删除等操作收进卡片右上角更多菜单，避免误触。

**空状态**：无作品时，以简短引导突出“新建作品”和“导入已有作品”，不展示无意义的空统计内容。

### 4.3 作品写作工作台

#### 顶部全局快捷栏（整书与全局级）

左侧保留返回书架入口、应用标识及当前作品名称与连载状态；右侧仅承载作用于**整部作品或全局环境**的轻量功能，按钮间保持轻量等距排布，不增加冗余分隔线：

- 全书检索（采用「书本 + 放大镜」组合图标，与单章查找作明确视觉区分）；
- 分屏对照开关；
- 主题切换（与书架页右上角保持完全统一的样式与交互）；
- 正文排版抽屉入口；
- 发布预设（独立管理全局发布格式，同时作用于复制与平台导出）。

顶部不承载完整文件管理菜单，也不出现富文本工具栏。

#### 左侧作品目录

目录按固定顺序组织：

1. **灵感与草稿箱**：固定置顶，可展开查看草稿；
2. **正文卷章树**：展示“卷 → 章”两级结构，支持展开、折叠、排序和跨卷移动；
3. **回收站**：固定置底，与正文目录保持视觉区分。

目录项与回收站入口保持安静无噪点，**不展示数量角标数字**；当前打开文档以柔和高亮底色及轻量指示点标明选中状态。新建、重命名、移动、删除等操作通过上下文菜单和明确的添加入口完成；拖拽作为效率增强，不作为唯一操作方式。

目录可折叠，为正文腾出空间。收起后仍保留恢复目录的轻量入口。

#### 中央写作区与章节栏（单章级）

写作区顶部栏位左侧显示当前卷章位置，右侧以纯图标轻量按钮集中承载**当前章节层级**的操作，按“编辑辅助”与“章节输出”自然分组：

- 编辑辅助：本章查找（纯放大镜图标）、历史快照、专注模式开关；
- 章节交付（同层级并列）：导出本章、复制本章（无边框轻量图标样式，保持视觉克制）。

单栏状态下，章节栏下方依次为：

- 独立章节标题输入框（按回车聚焦正文首段）；
- 正文编辑画布；
- 必要的临时提示，不长期占用正文空间。

正文采用居中的适宜版心，四周保留充足留白。段首缩进、对话高亮和场景分割线均只影响视觉呈现。打开章节后可直接延续上次编辑位置，切换章节时先确保当前内容保存。

#### 底部状态栏

保持低高度、低干扰，主要显示：

- 当前文档保存状态（如`保存中…`、`已保存`、`保存异常`）；
- 云端连接状态（以「云图标 + 状态圆点」简洁呈现，不展示文字、也不设点击弹窗交互：绿色圆点表示已连接云端，本地修改将同步至云端；暖橙色圆点表示未连接，避免使用刺眼的红色）；
- 本章有效字数及必要的外部同步/异常提示。

鼠标悬停在云图标或状态圆点上时，以轻量一行提示展示当前连接状态；若处于未连接状态，则在提示下方以小字说明具体原因（如未接入云盘同步目录或同步服务未运行）。点击字数区域打开字数明细，并可进一步进入码字统计日历。保存异常等状态需比普通状态更明确。

### 4.4 双栏对照视图

开启后，中央写作区分为左右两栏，每栏拥有独立的文档选择、标题、正文和滚动位置；中间分隔线支持拖动调整宽度。

- 默认可将当前文档保留在右侧，左侧用于打开大纲、草稿或前一章；
- 左右打开同一文档时，内容实时一致，但各自滚动位置独立；
- 顶部提供明确的退出分屏入口；
- 专注模式与分屏可以同时使用，退出专注后恢复原目录布局。

### 4.5 专注模式

专注模式归属章节层级，可通过章节栏按钮或快捷键（`F11`）进入。进入后自动隐藏最上方全局快捷栏、左侧目录及底部状态栏，仅保留正文、标题及极简的退出按钮（支持 `Esc` 退出）；鼠标移近章节顶部区域时，可临时呼出章节操作。

在正文排版抽屉中提供“打字机居中滚动”开关，开启后专注模式下当前输入行保持在视野中部舒适位置。退出专注模式后恢复进入前的目录、分屏和文档状态。

## 5. 辅助功能界面

### 5.1 全局检索与单章查找替换

- **全书检索**：由顶栏「书本 + 放大镜」图标或快捷键触发，使用居中浮层展示匹配文档名称和上下文摘要；点击结果后打开对应文档并定位命中位置。
- **单章查找替换**：由章节栏纯放大镜图标或快捷键触发，在编辑区上方显示轻量浮层，提供匹配导航、数量、大小写选项及替换操作；关闭浮层时清理临时高亮且不影响正文滚动位置。

### 5.2 历史快照与版本对比

历史快照以右侧抽屉呈现，按时间排列并区分手动与自动快照。选择版本后进入左右对比视图，一侧为历史内容，一侧为当前正文，并突出文本差异。

恢复操作需要明确确认；执行前自动为当前正文保留保护快照，并通过提示告知用户。

### 5.3 回收站

回收站以独立管理视图或较大的抽屉展示，包含项目名称、原位置、删除时间和剩余保留天数。

支持预览、恢复、批量选择和彻底删除。彻底删除与清空回收站必须使用明确的不可逆确认；普通恢复则尽量保持一步完成。

### 5.4 字数明细与码字日历

- **字数明细**：从底部状态栏弹出小卡片，展示本章统计、今日净增和全书总字数。
- **码字日历**：使用独立页面或大弹窗，以年度热力图为主体，配合连续创作天数、月度与年度累计等摘要；支持切换书库汇总与单部作品视图。

### 5.5 主题、排版与发布交付

- **全局主题切换**：通过书架首页右上角及工作台顶栏统一的「主题」按钮唤起小型浮层，支持一键切换纯白、羊皮纸、淡绿、暗夜四套主题，即时作用于所有界面与画布。
- **正文排版设置**：采用侧边抽屉，专注调节正文字体、字号、行高、段落间距、版心宽度、段首缩进、对话高亮及打字机居中滚动开关，所有调整实时预览并自动保存。
- **发布格式预设**：由工作台顶栏独立的「预设」按钮打开设置浮层，统一管理段首补齐全角空格、段间空行、场景分割线和首行附带标题规则；配置修改后自动生效，不与单一复制按钮绑定，同时应用于「复制本章」与「平台格式导出」。
- **单章导出与复制**：二者作为同级交付动作并列置于章节栏右侧。「复制本章」直接按当前发布预设转换文本并写入剪贴板；「导出本章」提供「纯净原稿格式」与「平台发布格式」两种 `.txt` 导出模式，通过系统路径选择界面保存独立副本，不改动书库原稿。

## 6. 关键流程与异常反馈

### 6.1 新建与导入作品

新建作品使用单一简洁弹窗，依次填写名称、封面和连载状态。导入流程采用“选择来源 → 识别与预览 → 确认导入”的步骤；批量章节导入需在确认前展示排序结果及编码、净化处理说明。

原始文件不会被修改这一点应在导入确认处明确说明。

### 6.2 外部变更与版本冲突

无冲突的外部更新以短暂轻提示告知，不打断写作。存在冲突时，使用模态对比界面展示本地版本与外部版本，并提供：

- 保留本地版本；
- 采用外部版本；
- 将冲突内容另存至草稿箱。

在冲突处理完成前，不静默覆盖任何一方内容。

### 6.3 保存与操作结果

正常自动保存不需要弹窗，仅更新状态栏。复制成功、导入完成、恢复成功等使用轻量 Toast；保存失败、文件占用、彻底删除等需要更明确且可持续查看的反馈。

所有危险确认都应说明影响对象、是否改动本地文件以及能否恢复，避免只使用笼统的“是否确认”。

## 7. 窗口适配与可访问性

- 宽窗口下保持完整目录与写作区；窗口变窄时优先收窄目录，再允许目录折叠为临时抽屉。
- 双栏模式需要设置合理的最小可用宽度，空间不足时提示用户先关闭目录或退出分屏，而不是过度压缩正文。
- 支持 Windows 与 macOS 常用快捷键，并在菜单或悬停提示中展示对应按键。
- 不仅依赖颜色表达选中、云端连接、保存异常、冲突和危险状态，同时配合文字、图标或清晰的悬停/无障碍说明。
- 弹窗、抽屉、目录树和编辑器均需支持清晰的键盘焦点与基本无障碍操作。

---

## 8. V1 界面边界

V1 不展示世界书、AI 辅助、行内批注、富文本格式工具栏及整书导出等后续功能入口。可以为未来扩展保留布局能力，但不在当前界面放置不可用的占位按钮。

初稿优先保证以下主路径完整、连贯：

```text
选择书库 → 新建或导入作品 → 管理卷章与草稿 → 专注写作
→ 自动保存与历史保护 → 检索或对照修改 → 复制发布 / 导出单章
```
